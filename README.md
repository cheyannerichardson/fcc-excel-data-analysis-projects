# 🌏Excel for Real-World Applications  
**Expanded Projects from FreeCodeCamp’s Microsoft Excel Beginner Course**

## Overview  
This repository expands upon the FreeCodeCamp Microsoft Excel tutorial for beginners by developing real-world projects that apply Excel table functions, formulas, and database management concepts to professional scenarios in **historical restoration, urban planning, and architecture**.  

These projects demonstrate how Excel evolves from a simple spreadsheet tool into a **powerful data management and decision-support system**, enabling professionals to analyze, model, and present complex data effectively.

## Project Overview

| # | Project Title | Description |
|---|----------------|--------------|
| **1** | **Heritage Restoration Payroll Tracker** | Models how Excel can manage payroll, materials, and expenses in restoration projects. Improves coordination, transparency, and financial accountability while maintaining compliance with grant requirements. |
| **2** | **Stanley Park Seawall Gradebook** | Demonstrates a weighted gradebook system in Excel to organize and evaluate community input on redesign proposals. Uses real environmental, social, and design factors to support balanced, data-driven decisions. |
| **3** | **Tokkia Matcha House Sales Database** | Builds an integrated workbook for small business management. Tracks sales, costs, and procurement to help manage budgets, suppliers, and timelines through a connected and interactive Excel dashboard. |
| **4** | **Washington Lighthouse Decision Matrix** | Uses a weighted Excel decision matrix to rank preservation priorities for historic lighthouses based on environmental conditions, cultural value, and cost-effectiveness. |
| **5** | **Stanley Park Seawall Traffic Inventory** | Creates a dynamic vehicle and mode tracking system for traffic analysis. Identifies congestion, conflicts, and usage trends to inform safer, more efficient design planning. |
| **6** | **Stanley Park Climate Risk Analysis** | Develops a climate risk and impact tracking tool for urban planners. Evaluates flood, erosion, and climate threats to guide long-term resilience planning for waterfront environments. |

#### Each project provides a practical model of how Excel evolves from a spreadsheet tool to a comprehensive data management and planning system across these professions.

## Database Management Focus  
Each project introduces methods for **transforming Excel tables into relational-style databases**, building foundational skills for integrating with professional database management systems (DBMS) such as **Microsoft Access, SQLite, or cloud-based solutions**.  

### Key Takeaways  
- Table normalization and data validation for clean data.  
- Query-like analysis using lookup functions and pivot tables.  
- Integration with external datasets for large-scale analytics.
